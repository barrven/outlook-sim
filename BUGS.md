## B001 — Settings screen had no way to close

**Reported:** 2026-09-11
**Fixed:** 2026-09-11
**Status:** fixed

Opening Settings (via the nav-rail "Settings" button, feature 010) had no
way to close once open — clicking a mail folder in the left nav didn't
return to the Mail view, since `App.tsx`'s `handleSelectFolder` never
cleared `showSettings`. The Mail/Calendar switcher happened to close it
(it unconditionally clears `showSettings`), so the gap only showed up via
the folder list.

**Fix:** `handleSelectFolder` now also clears `showSettings`, and
`SettingsView.tsx` got its own explicit header with a close (✕) button
wired to an `onClose` prop, so there's a direct way out regardless of
what else changes later.

**Files:** `src/renderer/src/App.tsx`, `src/renderer/src/components/SettingsView.tsx`,
`src/renderer/src/styles/global.css`
